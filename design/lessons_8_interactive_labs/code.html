Expected Outcome

The producer blocks until Broker 1 (Leader) and both ISR followers (Broker 2 & Broker 3) persist the record to their local logs, guaranteeing zero data loss if a single broker fails.

Technical Explanation

With acks=all (equivalent to -1), the leader waits for all replicas in the current In-Sync Replica (ISR) set to acknowledge the batch. Combined with min.insync.replicas=2, this prevents unacknowledged writes from being lost during leader election.
